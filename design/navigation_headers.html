Behaviors & Alignment Rules
check_circle Unread Notification Pip: 8px solid primary dot pinned `top: 8px, right: 8px` inside action circle, with a 2px mask ring matching the container background.
check_circle Touch Press State: Buttons trigger `scale(0.97)` physical response with a 150ms spring curve to preserve tactile hardware quality.
check_circle Subpage Chevron Hit Box: 26px SF-style left chevron padded seamlessly into the leading edge without pushing the screen label off-axis.

Navigation & State Rules

palette
Highlight Rule: The current page's icon is highlighted: Settings → gear active; Notifications → bell active; everywhere else both are neutral.
circle_notifications
Unread Indicator: The bell shows the pink pip only when there are unread notifications.
space_dashboard
Layout Safety: On stack pages the title is left-aligned next to the chevron so a page action never collides with it.
